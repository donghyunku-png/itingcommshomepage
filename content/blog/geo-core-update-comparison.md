# 구글 코어 업데이트 직후, 검색 순위와 AI 인용을 따로 보는 법

홈페이지를 고친 다음 날, 구글 순위가 올랐습니다. 같은 날 AI 답변에서도 우리 회사 이름이 나왔습니다. 둘 다 좋은 관찰이지만, 하나가 다른 하나를 만들었다는 증거는 아닙니다. 검색 시스템 자체가 바뀌는 시기라면 **언제 바뀌었는지**와 **무엇을 측정했는지**부터 나눠야 합니다.

## 배포 중인 날짜를 따로 표시합니다

구글은 2026년 11월 코어 업데이트가 미국 태평양시간 11월 10일 시작해 11월 24일 오전 6시 3분(한국시간 11월 24일 오후 11시 3분)에 끝났다고 공지했습니다. 전 세계 모든 언어에 적용된 검색 순위 업데이트입니다. 이 공지는 개별 사이트의 순위 변화 원인이나 특정 AI 답변의 변경 사유를 알려주지 않습니다. [1]

구글은 완료 뒤 최소 일주일을 기다린 뒤 Search Console에서 배포 전 한 주와 비교하라고 권합니다. 국내 운영팀이라면 배포 시각을 한국시간으로 기록하되, 검색 보고서의 날짜 기준도 확인하세요. 배포 중 수치는 삭제하지 말고, 전후 비교와 구분해 보관합니다. [2]

## 순위, AI 답변, 클릭은 서로 다른 관찰값입니다

1. **검색 성과:** Search Console에서 검색 유형, 국가, 페이지, 쿼리를 같은 조건으로 맞추고 노출·클릭·평균 게재순위를 비교합니다. 사이트 전체 평균만 보면 어느 페이지가 움직였는지 놓치기 쉽습니다.
2. **AI 답변:** 같은 엔진과 질문, 언어·지역 조건을 유지하고 여러 번 확인합니다. 답변에서 회사가 언급됐는지, 어느 URL이 인용됐는지, 그 URL이 실제로 해당 문장을 뒷받침하는지를 별도로 기록합니다.
3. **사이트 유입:** Google의 AI 검색 기능 트래픽은 Search Console의 웹 검색 유형에 합산됩니다. 이 숫자만으로 AI 기능에서 발생한 클릭을 분리 집계하거나, 다른 AI 서비스에서의 언급 증가까지 판단할 수는 없습니다. [3]

예를 들어 검색 노출이 늘었는데 같은 질문에서 AI 인용이 그대로라면, 우선 **검색 노출 증가만** 보고합니다. 반대로 AI가 새로 링크했지만 엉뚱한 서비스 페이지를 인용했다면 링크 수를 성과로 내기 전에 원문이 답변을 뒷받침하는지 확인합니다. 둘 다 설명을 위한 예시이며 실제 성과 수치가 아닙니다.

## 오늘 남겨 둘 한 줄

**변경일과 내용 / 관찰 기간 / 검색 유형 또는 AI 엔진 / 쿼리·질문 / 대상 URL / 결과 / 아직 모르는 점.** 오늘은 배포 종료일과 우리 사이트의 변경 이력을 기록하고, 비교 기간이 차면 같은 조건으로 다시 확인하세요. 실제로 틀린 상품 정보나 끊어진 페이지는 바로 바로잡되, 며칠치 순위 변화만으로 잘 작동하던 콘텐츠를 한꺼번에 고치지는 않는 편이 좋습니다.
