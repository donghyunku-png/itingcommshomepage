60MW인가, 110MW인가: AI 답변에서 숫자의 범위를 확인하는 법

안산 AI 데이터센터 보도를 예로, AI 답변이 숫자에 대상·범위·상태를 정확히 붙였는지 확인하는 방법을 정리합니다.

아이팅커뮤니케이션즈2026-11-27업데이트 2026-11-27

AI 답변에 출처 링크가 있고 원문에도 같은 숫자가 보이는데, 답변이 틀릴 수 있을까요? 숫자가 가리키는 대상을 바꾸면 그렇습니다. 새 시설 한 곳의 규모와 기존 시설을 포함한 전체 규모는 같은 기사에 있어도 서로 바꿔 쓸 수 없습니다.

안산2의 60MW와 캠퍼스의 110MW

11월 26일 보도에 따르면 KT클라우드가 추진하는 안산2 AI 데이터센터의 수전용량은 60MW입니다. 기존 안산 AI 데이터센터와 연계한 캠퍼스 전체의 계획 규모는 110MW입니다. 안산2는 2030년 내 서비스 개시가 목표로 보도됐습니다. 따라서 “안산2 한 곳이 110MW”나 “현재 110MW를 운영 중”이라는 설명은 이 보도를 근거로 쓸 수 없습니다. [1] [2]

이 숫자만으로 서버에 실제 배정되는 전력이나 설치된 GPU 수량을 알 수도 없습니다. 수전용량은 시설에 공급받는 전력 용량을 뜻합니다. 서버 장비가 사용하는 전력과 실제 사용량은 각각 별도의 근거가 필요합니다.

숫자를 확인할 때 같이 볼 세 가지

  1. 대상: 어떤 제품, 시설, 지역에 붙은 숫자인가요? 이름이 비슷한 두 대상을 먼저 분리하세요.
  2. 범위와 단위: 하나의 시설인지, 여러 시설의 합계인지 확인하세요. 같은 MW라도 수전용량인지 서버 전력인지 구분해야 합니다.
  3. 기준일과 상태: 발표된 계획인지, 확정된 일정인지, 이미 운영 중인 수치인지 확인하세요. 목표일은 실제 개시일처럼 쓰지 않습니다.

검수할 때는 “안산2의 수전용량, 안산 캠퍼스 전체 계획 규모, 안산2 서비스 개시 목표를 각각 알려주고, 각 수치를 뒷받침하는 출처를 붙여 주세요”라고 질문해 보세요. 이 질문은 설명을 위한 예시이며 실제 엔진 실험 결과가 아닙니다.

홈페이지에는 숫자 옆에 조건까지 적으세요

제품 사양이나 프로젝트 규모를 안내할 때는 대상명 + 수치와 단위 + 적용 범위 + 현재 상태를 같은 문장에 두세요. 표에서 단위나 조건을 각주에만 넣었다면 핵심 수치 옆에도 짧게 적는 게 좋습니다. 검수표에는 답변의 주장 / 대상·범위 / 상태와 기준일 / 원문 URL / 판정을 남겨 두면 다음에 수치가 바뀌었을 때 다시 확인하기 쉽습니다.
